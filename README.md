# BPMSoft IntelliSense

VS Code / Cursor extension: autocomplete and Go to Definition for BPMSoft/Creatio schemas and Ext modules.

## Features

### Schema pages (`this.`)

Uses `conf/content/{Schema}.js` Structures:

```js
BPMSoft.configuration.Structures["LeadPageV2"] = {
  innerHierarchyStack: ["LeadPageV2Lead", …, "LeadPageV2"],
  structureParent: "BaseLeadPage"
};
```

- Stack: left = base, right = most derived (**rightmost wins**)
- `LeadPageV2Lead` → `Pkg/Lead/...` or `Autogenerated/Src/LeadPageV2.Lead.js`
- Bare `LeadPageV2` → topmost package file
- Extra `Pkg/*/Schemas/{Schema}` not in stack still included
- `structureParent` walked recursively
- Mixins from all layers merged

### Modules (non-page)

Own file + `override` / `extend` (e.g. `BPMSoft.controls.Grid` → `Resources/ui/.../grid.js`).

### Globals

- `BPMSoft` / `Ext` / `define` while typing identifiers
- `BPMSoft.*` — enums (`SysValue`, `DataValueType`, …), classes (`SysSettings`, …), `configuration.Structures.*` from **this** project's `conf/content`
- `Ext.*` — `isEmpty`, `String`, `Array`, … (+ extract from `Resources/ui/ExtJs`)

### UX

- Indexed completions ranked above word/history suggestions (`bpmsoft.preferIndexedCompletions`)
- Command: **BPMSoft: Rebuild Index**

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| `bpmsoft.pkgGlob` | `**/Pkg/**/Schemas/**/*.js` | Package schemas |
| `bpmsoft.autogeneratedGlob` | `**/Autogenerated/Src/*.js` | Locked schemas |
| `bpmsoft.platformUiGlob` | `**/Resources/ui/BPMSoft/**/*.js` | Platform UI Ext classes |
| `bpmsoft.enablePlatformStubs` | `true` | BPMSoft.* stubs/enums |
| `bpmsoft.preferIndexedCompletions` | `true` | Suppress JS name/history suggestions in workspace |

## Develop

```bash
npm install
npm run compile
npm run smoke   # needs ../crm-volumes/bpmsoftdevelopment (or BPMSOFT_APP_ROOT)
```

**F5** — Extension Development Host with `bpmsoftdevelopment`.

## Package / install

```bash
npm run package
# Install from VSIX: bpmsoft-intellisense-0.1.0.vsix
```

Open any of:
- app root (`bpmsoftdevelopment`)
- `BPMSoft.Configuration`
- `BPMSoft.Configuration/Pkg`
- `BPMSoft.Configuration/Pkg/{PackageName}`

The extension detects the app layout and resolves `conf/`, `Resources/`, `Autogenerated/` relative to it (even outside the opened folder).
